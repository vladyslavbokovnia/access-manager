# Менеджер доступности для Android

Прототип Android-приложения на **Kotlin + Jetpack Compose**, которое собирает установленные службы специальных возможностей и предоставляет единый удобный список для управления ими.

## Возможности

- получение списка установленных служб через `AccessibilityManager`;
- отображение включённого/выключенного состояния;
- поиск по названию службы и имени пакета;
- сохранение пользовательского порядка между запусками;
- перемещение службы вверх или вниз кнопками в карточке;
- переход в общие настройки специальных возможностей;
- переход на страницу конкретной службы, где пользователь может включить или выключить её.

## Ограничения Android

Android не разрешает обычному стороннему приложению напрямую включать или выключать чужие службы специальных возможностей. Это действие намеренно требует подтверждения пользователя в системных настройках. Приложение поэтому открывает соответствующую страницу настроек и обновляет состояние после возврата.

Сортировка относится к списку внутри приложения и не меняет порядок служб в системном интерфейсе Android.

## Запуск

1. Откройте каталог в Android Studio Ladybug или новее.
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на Android 8.0+.
4. Для проверки установите на устройство несколько приложений со службами специальных возможностей.

Из командной строки после установки Android SDK можно выполнить:

```bash
./gradlew test
./gradlew assembleDebug
```

## Структура

- `app/src/main/java/.../MainActivity.kt` — Compose-интерфейс и переходы в настройки.
- `app/src/main/java/.../AccessibilityViewModel.kt` — загрузка служб, состояние и сохранение порядка.
- `app/src/test/.../AccessibilityOrderingTest.kt` — базовые тесты перемещения элементов.
